STEPS TO START

npm install client and server

Navigate in terminal to server directory and run (npm install)
Navigate in terminal to client directory and run (npm install)

Configure .env file

MONGO_URI=mongodb://localhost:27017/group-project
JWT_SECRET=MY_SUPER_SECRET_KEY

npm run dev | under server directory -- COMP229-Group-Project\server>
npm run dev | under client directory -- COMP229-Group-Project\client>
